Política de Privacidade

Última atualização: 12 de agosto de 2026

Esta Política explica como o GuiaZap coleta, usa e protege dados pessoais, em conformidade com a Lei Geral de Proteção de Dados (LGPD — Lei nº 13.709/2018).

1. Dados coletados

  • De quem se cadastra como profissional/empresa: nome, e-mail, CPF ou CNPJ, telefone/WhatsApp, categoria de atuação, endereço (estado, cidade, bairro, CEP), foto de perfil (opcional);
  • De visitantes que avaliam: nome informado e comentário, junto com a nota atribuída;
  • Dados técnicos: informações de navegação coletadas automaticamente pelos serviços de hospedagem (Netlify) para fins de segurança e desempenho.

2. Finalidade do uso dos dados

  • Exibir publicamente o cadastro de empresas/profissionais para busca por visitantes, conforme a própria natureza do serviço (diretório público);
  • Processar a cobrança da assinatura, por meio do Mercado Pago;
  • Autenticação e login na plataforma;
  • Comunicação sobre a conta (recuperação de senha, avisos de pagamento).

3. Compartilhamento de dados

O GuiaZap compartilha dados pessoais apenas com os seguintes prestadores, estritamente para viabilizar o funcionamento da plataforma:

  • Supabase — armazenamento do banco de dados e autenticação;
  • Mercado Pago — processamento de pagamentos (o GuiaZap não tem acesso a dados de cartão de crédito);
  • Netlify — hospedagem do site.

O GuiaZap não vende, aluga ou compartilha dados pessoais com terceiros para fins de publicidade.

Importante: os dados de contato (WhatsApp, categoria, localização) cadastrados por profissionais e empresas são, por natureza do serviço, exibidos publicamente para qualquer visitante do site — essa exposição é o próprio objetivo do cadastro, e o usuário concorda com isso ao se cadastrar.

4. Direitos do titular dos dados (LGPD)

Você pode, a qualquer momento, solicitar:

  • Confirmação de quais dados seus são tratados;
  • Correção de dados incompletos, inexatos ou desatualizados (diretamente pela edição do próprio cadastro, quando logado);
  • Exclusão do cadastro e da conta (também disponível diretamente pela plataforma, ao excluir o próprio cadastro);
  • Informações sobre com quem os dados são compartilhados.

Solicitações podem ser feitas por e-mail: contato@guiazap.shop

5. Segurança dos dados

O GuiaZap adota medidas técnicas razoáveis para proteger os dados armazenados, incluindo controle de acesso por autenticação e regras de segurança no banco de dados (Row Level Security), que garantem que cada usuário só possa editar ou excluir os próprios cadastros. Senhas de cartão de crédito nunca são armazenadas pelo GuiaZap.

6. Retenção de dados

Os dados são mantidos enquanto a conta estiver ativa. Ao excluir o cadastro ou solicitar a exclusão da conta, os dados pessoais são removidos, ressalvadas informações que a legislação exija manter (ex: registros fiscais de pagamento).

7. Alterações nesta Política

Esta Política pode ser atualizada periodicamente. A versão vigente é sempre a publicada nesta página.

8. Contato

Para dúvidas ou solicitações relacionadas aos seus dados pessoais: contato@guiazap.shop
