🔗 Sincronização automática (API)

Se sua empresa tem um sistema próprio (PDV, ERP), o pessoal técnico de lá pode usar essa chave pra manter os produtos sempre atualizados aqui automaticamente, sem precisar cadastrar de novo toda vez.

Como o sistema deles deve chamar: 
POST https://guiazap.shop/.netlify/functions/sincronizar-produtos-api
Content-Type: application/json

{
  "chave": "SUA_CHAVE_AQUI",
  "produtos": [
    {
      "codigo_externo": "PROD001",
      "nome": "X-Burguer",
      "preco": "18,00",
      "categoria": "Lanches",
      "descricao": "Pão, hambúrguer, queijo"
    }
  ]
}

Cada produto com o mesmo "codigo_externo" que já existe é ATUALIZADO, não duplicado. Produtos novos são criados automaticamente.
